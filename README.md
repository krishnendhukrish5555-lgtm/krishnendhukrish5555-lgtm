## 🧠 How I Approach Security

1. **Observe first:** understand the system, context, and available evidence before drawing conclusions.
2. **Validate findings:** distinguish a confirmed issue from an assumption or an interesting signal.
3. **Document clearly:** capture the steps, relevant evidence, impact, limitations, and possible remediation.
4. **Respect authorization:** practice in owned systems, intentionally vulnerable applications, or environments where testing is explicitly permitted.
5. **Keep learning:** review mistakes, improve the notes, and revisit fundamentals as understanding grows.
